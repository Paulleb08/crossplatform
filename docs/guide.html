Lancer un .exe Windows sur votre Mac

Ce guide vous mène de zéro à un jeu ou logiciel Windows lancé d'un double-clic. Tout est gratuit et open source, à part les outils d'Apple, gratuits eux aussi.

jeu.exe→Wine→D3DMetal ou DXVK→Metal→votre écran
Partie 1 · une seule fois · ~15 min

Préparer le Mac

Ouvrez l'app Terminal (Cmd+Espace, tapez « Terminal »), puis copiez chaque commande. Cochez les étapes au fur et à mesure : votre navigateur s'en souviendra.

  1. Vérifier que le Mac est Apple Silicon

    Disponible

    La commande doit afficher arm64. Il faut aussi macOS 14 Sonoma ou plus récent (menu Pomme → À propos de ce Mac).

    uname -m

  2. Installer Rosetta 2

    Disponible

    Wine est un programme Intel : Rosetta le fait tourner sur la puce Apple.

    softwareupdate --install-rosetta --agree-to-license

  3. Installer Homebrew

    Disponible

    Le gestionnaire de paquets qui installera le reste. Suivez les deux lignes « Next steps » qu'il affiche à la fin.

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

  4. Installer Wine avec D3DMetal, puis Winetricks

    Disponible

    Ce paquet regroupe Wine et la couche D3DMetal du Game Porting Toolkit d'Apple. Winetricks installe les composants Windows (Visual C++, polices…).

    brew install --cask gcenx/wine/game-porting-toolkit brew install winetricks

    Si macOS bloque Wine au premier lancement : xattr -dr com.apple.quarantine "/Applications/Game Porting Toolkit.app". Autre option : télécharger le Game Porting Toolkit sur developer.apple.com (compte Apple gratuit).

  5. Facultatif : DXVK pour les jeux récalcitrants

    Disponible

    Certains jeux DirectX 9 à 11 fonctionnent mieux avec DXVK. Il passe par Vulkan, que MoltenVK traduit en Metal.

    brew install molten-vk
Partie 2 · pour chaque programme · ~5 min

Lancer votre .exe avec Cellier

Une bouteille est un faux disque Windows 10 rangé dans un dossier. Elle est isolée du reste du Mac, et vous pouvez en avoir une par jeu.

  1. Installer Cellier

    Disponible

    Une seule fois. Cellier n'a besoin que du Python fourni avec macOS. Vérifiez ensuite que la commande répond.

    git clone -b claude/laughing-edison-cw7fyk https://github.com/paulleb08/crossplatform ~/cellier pip3 install --user ~/cellier cellier list

    Si cellier est introuvable, ajoutez ~/Library/Python/3.x/bin à votre PATH. Vous pouvez aussi utiliser python3 -m cellier depuis le dossier ~/cellier/src.

  2. Créer une bouteille

    Disponible

    Cellier crée un Windows 10 64-bit et installe Visual C++ 2015-2022, les polices Windows et d3dcompiler_47. Comptez quelques minutes la première fois.

    cellier create MesJeux

  3. Installer ou lancer votre programme

    Disponible

    Glissez le fichier dans le Terminal après le nom de la bouteille pour coller son chemin. Cellier accepte .exe, .msi et les images disque .iso, qu'il monte tout seul.

    cellier run MesJeux ~/Downloads/setup.exe

  4. Créer une icône pour lancer en un clic

    Disponible

    Indiquez le chemin du programme installé, côté Windows. L'app apparaît dans ~/Applications/Cellier : glissez-la dans le Dock.

    cellier shortcut MesJeux "C:\Games\MonJeu\MonJeu.exe" --name "Mon Jeu"

  5. Si l'image est noire ou le jeu plante

    Disponible

    Changez de moteur graphique sans recréer la bouteille, puis relancez.

    # DirectX 9/10/11 récalcitrant : essayer DXVK cellier config MesJeux --graphics dxvk --sync esync # Revenir au réglage par défaut (DirectX 11/12) cellier config MesJeux --graphics d3dmetal --sync msync

    Pour DXVK, déposez d'abord les DLL x64 de DXVK-macOS (d3d11.dll, d3d10core.dll, dxgi.dll) dans ~/Library/Application Support/Cellier/Components/dxvk/x64. Le retour à D3DMetal restaure les DLL d'origine.

Repères

Quel réglage choisir ?

RéglagePour quoiQuand l'utiliser
d3dmetalDirectX 11 et 12 → Metal (Apple)Par défaut, jeux récents
dxvkDirectX 9 à 11 → Vulkan → MetalJeux plus anciens, bugs graphiques avec D3DMetal
msyncSynchronisation des threads via MetalPar défaut, le plus rapide
esyncSynchronisation par événementsAvec DXVK, ou si un jeu se fige avec MSync
